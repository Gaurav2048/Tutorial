CANVAS + MATH + REACT · A HANDS-ON GUIDE

From glowing dots
to flowing waves.

Build the animation you requested, understand every transformation, and carry it into a reusable React component.

Start with the finished effect below. Then work through the lessons: pixels → points → sphere → breathing → morph → waves → React. You only need JavaScript functions, arrays, and basic React hooks. No graphics library or advanced calculus is required.

The timing: the sphere completes one expand–contract cycle from 0–2 seconds. At 2 seconds it starts unfolding. At 4.2 seconds it reaches the plane, and the waves fade in over the next 1.5 seconds. Waves then continue. Replay starts the sequence again.

LESSON 01

Think in frames, then draw a dot.

A canvas is a surface you repaint. It does not remember shapes as DOM elements. For every frame: clear the old picture, calculate positions at the current time, and draw the next picture.

Start with this small runnable HTML file. Save it as dot.html and open it in your browser. You should see one mint dot centered on a dark surface.

<!doctype html>
<html><body style="margin:0;background:#060d12">
<canvas id="canvas" style="width:100%;height:400px"></canvas>
<script>
const canvas = document.querySelector('#canvas');
const ctx = canvas.getContext('2d');
function draw() {
  const { width, height } = canvas.getBoundingClientRect();
  const dpr = Math.min(devicePixelRatio || 1, 2);
  canvas.width = Math.round(width * dpr);
  canvas.height = Math.round(height * dpr);
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  ctx.clearRect(0, 0, width, height);
  ctx.fillStyle = '#8fffe5';
  ctx.beginPath();
  ctx.arc(width / 2, height / 2, 4, 0, Math.PI * 2);
  ctx.fill();
}
new ResizeObserver(draw).observe(canvas);
</script></body></html>

Why two sizes? CSS controls the displayed size. The canvas width/height attributes control the bitmap resolution. Multiplying by device pixel ratio keeps the drawing sharp; scaling the context lets us still use CSS pixels in our calculations. Changing bitmap size resets the context, so set the transform again after resizing.

Try it: move the dot by changing width / 2 to width * .7. This is the same idea used later to move the plane right.

LESSON 02

Give every point a soft halo.

A glowing dot has a bright center and a transparent edge. A radial gradient supplies that falloff. Drawing thousands of gradients every frame is unnecessary: draw one glow into a small offscreen canvas, then stamp copies of that image onto the main canvas.

The snippets from here explain the parts of the final engine. They are not separate full applications; the complete runnable files are provided in lesson 9.

const sprite = document.createElement('canvas');
sprite.width = sprite.height = 64;
const sc = sprite.getContext('2d');
const g = sc.createRadialGradient(32, 32, 0, 32, 32, 32);
g.addColorStop(0, 'rgba(143,255,229,1)');
g.addColorStop(.08, 'rgba(143,255,229,.98)');
g.addColorStop(.19, 'rgba(143,255,229,.32)');
g.addColorStop(.5, 'rgba(143,255,229,.07)');
g.addColorStop(1, 'rgba(143,255,229,0)');
sc.fillStyle = g;
sc.fillRect(0, 0, 64, 64);

// Repeat for every projected particle:
ctx.globalAlpha = opacity;
ctx.drawImage(sprite, x - size, y - size, size * 2, size * 2);
ctx.globalAlpha = 1;

size is the radius of the sprite, including its faint halo. globalAlpha multiplies the gradient’s own transparency. Increase size and opacity together to make a particle feel more energetic.

Check: the outer edge should disappear into the background. A visible square means your last gradient stop is not transparent. The engine itself paints no background, so it can sit over your own page.

LESSON 03

Wrap a grid around a sphere.

Give each particle an identity using a row and column. Normalize these to u and v between 0 and 1. These coordinates will later also tell us where that same particle belongs on the plane.

For the sphere, pick a vertical coordinate sy between −1 and 1. A horizontal slice at that height has radius sqrt(1 − sy²), from the circle equation. Cosine and sine walk around that slice.

const columns = 68, rows = 38;
const points = [];
for (let row = 0; row < rows; row++) {
  for (let col = 0; col < columns; col++) {
    const u = col / (columns - 1);
    const v = row / (rows - 1);
    const longitude = u * Math.PI * 2;
    const sy = 1 - 2 * (row + .5) / rows;
    const circle = Math.sqrt(1 - sy * sy);
    points.push({
      sx: Math.cos(longitude) * circle,
      sy,
      sz: Math.sin(longitude) * circle,
      u, v
    });
  }
}

Units: these coordinates describe a sphere of radius 1, not pixels. We scale them later. Math.PI * 2 is one full turn in radians. Starting each row halfway into its height band avoids stacking an entire row at either pole.

The two end columns overlap at the sphere seam. That small duplication is intentional here: those two ends separate into the left and right edges when the surface unfolds. This regular grid produces orderly waves; randomly rebuilding particles would destroy that correspondence.

LESSON 04

Make 3D points fit a 2D screen.

Our camera looks toward the origin from positive Z. Points with larger Z are closer, so they should appear larger. Divide by distance from the camera to get a simple perspective multiplier.

const cameraDistance = 6;
const perspective = cameraDistance / (cameraDistance - z);
const screenX = centerX + x * scale * perspective;
const screenY = centerY + y * scale * perspective;

// Rotate the sphere gently around Y before projecting it:
const sphereX = (sx * Math.cos(spin) + sz * Math.sin(spin)) * radius;
const sphereZ = (-sx * Math.sin(spin) + sz * Math.cos(spin)) * radius;

For z = 0, the multiplier is 1. At z = 1, it is 1.2. At z = −1, it is about .86. Keep all points well below Z = 6 or the denominator approaches zero.

Canvas Y increases downward, so positive Y goes down on screen. This does not prevent a convincing sphere; keep the convention consistent. Sort points by Z from far to near before painting, and give near points a little more size and opacity.

The rendering pipeline: create local coordinates → rotate them → blend shapes → position and project them → draw glow sprites. Rotating projected screen coordinates would lose the correct depth relationship.
LESSON 05

Make the sphere breathe.

A sine or cosine gives us smooth repetition. We want a value that starts at 0, rises to 1, then returns to 0. The formula below does exactly that over two seconds.

const breath = .5 - .5 * Math.cos(time * Math.PI);
const radius = 1.06 * (.86 + .22 * breath);
const glowEnergy = .72 + .56 * breath;
const opacityEnergy = .72 + .28 * breath;

// time is seconds accumulated between animation frames:
let time = 0, last = 0;
function frame(now) {
  if (last) time += Math.min((now - last) / 1000, .05);
  last = now;
  draw(time);
  requestAnimationFrame(frame);
}

At 0 seconds, breath = 0; at 1 second, breath = 1; at 2 seconds, breath = 0. Multiplying the sphere’s coordinates by radius expands the whole sphere. Multiplying sprite size and opacity by the other values makes its glow breathe with it.

The browser supplies now in milliseconds. Convert to seconds so speed does not depend on frame rate. The .05 cap avoids large jumps after a stall; it also means this is active animation time, not a strict wall-clock deadline during heavy lag. The final engine pauses time when hidden.

LESSON 06

Unfold the same points into a tilted plane.

A morph is interpolation between two positions. Each point already knows its sphere position. Its plane position comes from the same u, v: subtract .5 to center the grid, then multiply by the desired width and height.

Progress is 0 until two seconds have elapsed, then rises to 1 over 2.2 seconds. A quintic easing curve starts and ends with zero slope and curvature, avoiding abrupt acceleration at the boundaries.

const clamp = x => Math.max(0, Math.min(1, x));
const mix = (a, b, t) => a + (b - a) * t;
function smooth(x) {
  const v = clamp(x);
  return v * v * v * (v * (v * 6 - 15) + 10);
}
const morph = smooth((time - 2) / 2.2);
const x = (u - .5) * 4.25;
const y = (v - .5) * 3;
const z = 0; // Later replaced with a wave height.

// Tip the plane around X so we see it in perspective.
const inclination = .93;
const py = y * Math.cos(inclination) - z * Math.sin(inclination);
const pz = y * Math.sin(inclination) + z * Math.cos(inclination);
// Then rotate around Z to create a diagonal composition.
const angle = -.24;
const px = x * Math.cos(angle) - py * Math.sin(angle);
const ry = x * Math.sin(angle) + py * Math.cos(angle);

const wx = mix(sphereX, px, morph);
const wy = mix(sy * radius, ry, morph);
const wz = mix(sphereZ, pz, morph);
const centerX = width * mix(.43, .61, morph);

The X tilt is about 53° and the Z tilt about −14°. Z rotation changes the plane’s diagonal direction; the X rotation gives it depth. Order matters: X then Z gives a different result from Z then X.

The final engine uses .55 instead of .61 for the destination center on small screens and shrinks the field slightly during the morph to keep the right edge visible. Translation is applied after rotation so the shape moves as a whole.

Why it stays continuous: no particles disappear and no new grid is generated during the transition. Particle 100 always interpolates from its own sphere coordinate to its own plane coordinate.

LESSON 07

Move a wave through the plane.

Keep each point’s X and Y fixed in the plane’s local space. Change only its local Z height. Then apply the same rotations and projection. This bends the surface instead of sliding the entire plane.

The expression sin(x * frequency − time * speed) creates a traveling wave. Adding a Y term turns its direction diagonally. Combining two waves gives a richer surface.

const waveTime = Math.max(0, time - 2 - 2.2);
const waveIn = smooth(waveTime / 1.5);
const z = waveIn * (
  .22 * Math.sin(x * 1.7 - waveTime * 1.25 + y * .9)
  + .12 * Math.sin(y * 2.4 + waveTime * .82 - x * .65)
);
// Feed this z into the X/Z rotations from lesson 6. Nodes stay
// at the same local x/y; their heights change continuously.

LESSON 08

Let React own the lifecycle, not each frame.

React creates the canvas. A ref gives the engine its DOM element. The engine owns its animation loop and returns methods for pause, replay, and cleanup. Do not put thousands of point coordinates in React state or call a state setter on every frame.

This is the minimal integration pattern. The downloadable wrapper adds configurable options, pause handling, and a callback ref to avoid stale callbacks.

import { useEffect, useRef } from 'react';
import { createParticleMorph } from './particleMorph.js';

export default function ParticleExample() {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  useEffect(() => {
    if (!canvasRef.current) return;
    const scene = createParticleMorph(canvasRef.current);
    return () => scene.destroy();
  }, []);
  return <canvas ref={canvasRef}
    role="img" aria-label="A glowing sphere unfolds into waves"
    style={{ width: '100%', height: 500, display: 'block' }} />;
}

Cleanup is required. Cancel animation frames, disconnect resize/intersection observers, and remove listeners on unmount. React development Strict Mode can run setup → cleanup → setup; a correctly cleaned-up engine still has only one active loop.

Accessibility: the final engine respects reduced-motion preferences by showing a static wave plane. It pauses when offscreen and when the tab is hidden. Keep important information outside the canvas. If the effect is purely decorative, you can use aria-hidden="true" instead of an image label in your own wrapper.

LESSON 09

Put the complete version in your app.

The files below are the actual source used for the original effect. Download the first three into the same folder in your existing React + TypeScript project. React is the only runtime package needed by the wrapper; the renderer uses browser APIs.

The .d.ts file describes the JavaScript engine’s types for TypeScript. Keep it beside particleMorph.js. Changing color, tilt, glow, durations, or replayKey rebuilds the scene in this wrapper; these are configuration props, not live per-frame controls. Pausing preserves time.

Use color="#c10007" for Jailbreak crimson. The canvas is transparent. Soft luminous particles read best against a dark surface; a white surface needs darker, more opaque dots and a subtler halo.

/** Dependency-free Canvas 2D projection of a 3D particle field. */
export function createParticleMorph(canvas, options = {}) {
  const settings = { color: '#8fffe5', sphereDuration: 2, morphDuration: 2.2, tilt: -0.24, glow: 1, onPhaseChange: () => {}, ...options };
  const ctx = canvas.getContext('2d', { alpha: true });
  if (!ctx) throw new Error('Canvas 2D is unavailable.');
  const hex = /^#[0-9a-f]{6}$/i.test(settings.color) ? settings.color : '#8fffe5';
  const rgb = [1, 3, 5].map(i => parseInt(hex.slice(i, i + 2), 16));
  const hold = Math.max(0, settings.sphereDuration), duration = Math.max(0.2, settings.morphDuration);
  const clamp = x => Math.max(0, Math.min(1, x));
  const smooth = x => { const v = clamp(x); return v * v * v * (v * (v * 6 - 15) + 10); };
  const mix = (a, b, t) => a + (b - a) * t;
  const points = [];
  const columns = 68, rows = 38;
  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < columns; col++) {
      const u = col / (columns - 1), v = row / (rows - 1);
      const longitude = u * Math.PI * 2;
      const sy = 1 - 2 * (row + 0.5) / rows;
      const circle = Math.sqrt(1 - sy * sy);
      points.push({ sx: Math.cos(longitude) * circle, sy, sz: Math.sin(longitude) * circle, u, v });
    }
  }
  const sprite = document.createElement('canvas'); sprite.width = sprite.height = 64;
  const sc = sprite.getContext('2d');
  const gradient = sc.createRadialGradient(32, 32, 0, 32, 32, 32);
  gradient.addColorStop(0, `rgba(${rgb},1)`); gradient.addColorStop(.08, `rgba(${rgb},.98)`);
  gradient.addColorStop(.19, `rgba(${rgb},.32)`); gradient.addColorStop(.5, `rgba(${rgb},.07)`); gradient.addColorStop(1, `rgba(${rgb},0)`);
  sc.fillStyle = gradient; sc.fillRect(0, 0, 64, 64);
  let width = 1, height = 1, time = 0, last = 0, raf = 0, paused = false, disposed = false, visible = true, phase = '';
  const reduced = window.matchMedia('(prefers-reduced-motion: reduce)');
  function draw() {
    ctx.clearRect(0, 0, width, height);
    const t = reduced.matches ? hold + duration + 2 : time;
    const morph = smooth((t - hold) / duration);
    const waveTime = Math.max(0, t - hold - duration);
    const waveIn = smooth(waveTime / 1.5);
    const nextPhase = t < hold ? 'sphere' : t < hold + duration ? 'morph' : 'waves';
    if (nextPhase !== phase) { phase = nextPhase; settings.onPhaseChange(phase); }
    // A complete inhale/exhale occurs during the first two seconds.
    const breath = .5 - .5 * Math.cos(t * Math.PI);
    const radius = 1.06 * (0.86 + .22 * breath);
    const spin = .28 + Math.min(t, hold) * .16;
    const scale = Math.min(width / 6.5, height / 3.55) * mix(1, .88, morph);
    const centerX = width * mix(.43, width < 520 ? .55 : .61, morph);
    const centerY = height * .51;
    const inclination = .93;
    const angle = settings.tilt;
    const ca = Math.cos(angle), sa = Math.sin(angle), ci = Math.cos(inclination), si = Math.sin(inclination);
    const projected = points.map(p => {
      const sphereX = (p.sx * Math.cos(spin) + p.sz * Math.sin(spin)) * radius;
      const sphereZ = (-p.sx * Math.sin(spin) + p.sz * Math.cos(spin)) * radius;
      const x = (p.u - .5) * 4.25;
      const y = (p.v - .5) * 3.0;
      const z = waveIn * (.22 * Math.sin(x * 1.7 - waveTime * 1.25 + y * .9) + .12 * Math.sin(y * 2.4 + waveTime * .82 - x * .65));
      const py = y * ci - z * si;
      const pz = y * si + z * ci;
      const px = x * ca - py * sa;
      const ry = x * sa + py * ca;
      const wx = mix(sphereX, px, morph), wy = mix(p.sy * radius, ry, morph), wz = mix(sphereZ, pz, morph);
      const perspective = 6 / (6 - wz);
      const depth = clamp((wz + 1.7) / 3.4);
      const energy = mix(.72 + breath * .56, .95 + .15 * Math.sin(x * 1.7 - waveTime * 1.25 + y * .9) * waveIn, morph);
      const size = Math.max(.48, scale / 190) * (3.4 + depth * 3.6) * energy * Math.max(.2, settings.glow);
      return { x: centerX + wx * scale * perspective, y: centerY + wy * scale * perspective, z: wz, size, alpha: (.13 + depth * .63) * mix(.72 + breath * .28, 1, morph) };
    });
    projected.sort((a, b) => a.z - b.z);
    ctx.globalCompositeOperation = 'source-over';
    for (const p of projected) {
      ctx.globalAlpha = p.alpha;
      ctx.drawImage(sprite, p.x - p.size, p.y - p.size, p.size * 2, p.size * 2);
    }
    ctx.globalAlpha = 1;
  }
  function frame(now) {
    raf = 0;
    if (disposed || paused || document.hidden || !visible || reduced.matches) return;
    if (last) time += Math.min((now - last) / 1000, .05);
    last = now; draw(); raf = requestAnimationFrame(frame);
  }
  function sync() {
    cancelAnimationFrame(raf); raf = 0; last = 0;
    if (disposed) return;
    draw();
    if (!paused && !document.hidden && visible && !reduced.matches) raf = requestAnimationFrame(frame);
  }
  function resize() {
    const rect = canvas.getBoundingClientRect();
    width = Math.max(1, rect.width); height = Math.max(1, rect.height);
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = Math.round(width * dpr); canvas.height = Math.round(height * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0); draw();
  }
  const resizeObserver = new ResizeObserver(resize); resizeObserver.observe(canvas);
  const intersection = new IntersectionObserver(([entry]) => { visible = entry.isIntersecting; sync(); }); intersection.observe(canvas);
  reduced.addEventListener('change', sync); document.addEventListener('visibilitychange', sync);
  resize(); sync();
  return {
    replay() { time = 0; paused = false; sync(); },
    setPaused(value) { paused = value; sync(); },
    destroy() { disposed = true; cancelAnimationFrame(raf); resizeObserver.disconnect(); intersection.disconnect(); reduced.removeEventListener('change', sync); document.removeEventListener('visibilitychange', sync); },
  };
}

import { useEffect, useRef } from 'react';
import type { CSSProperties } from 'react';
import { createParticleMorph } from './particleMorph.js';
import type { ParticleOptions } from './particleMorph.js';

export type ParticleMorphProps = ParticleOptions & {
  className?: string;
  style?: CSSProperties;
  paused?: boolean;
  /** Change this value to restart the sphere → plane sequence. */
  replayKey?: number;
};
export default function ParticleMorph({ color = '#8fffe5', sphereDuration = 2, morphDuration = 2.2, tilt = -0.24, glow = 1, paused = false, replayKey = 0, onPhaseChange, className, style }: ParticleMorphProps) {
  const ref = useRef<HTMLCanvasElement>(null);
  const controller = useRef<ReturnType<typeof createParticleMorph> | null>(null);
  const phaseCallback = useRef(onPhaseChange); phaseCallback.current = onPhaseChange;
  useEffect(() => {
    if (!ref.current) return;
    const scene = createParticleMorph(ref.current, { color, sphereDuration, morphDuration, tilt, glow, onPhaseChange: phase => phaseCallback.current?.(phase) });
    controller.current = scene;
    return () => { scene.destroy(); controller.current = null; };
  }, [color, sphereDuration, morphDuration, tilt, glow, replayKey]);
  useEffect(() => controller.current?.setPaused(paused), [paused, color, sphereDuration, morphDuration, tilt, glow, replayKey]);
  return <canvas ref={ref} className={className} role="img" aria-label="A glowing particle sphere breathes, unfolds into a tilted plane, drifts right, then flows in waves." style={{ display: 'block', width: '100%', height: 'clamp(320px, 52vw, 620px)', ...style }} />;
}

Understand the final engine’s draw function

  1. Choose the current time; reduced-motion mode selects a static final pose.
  2. Calculate morph progress, wave fade-in, breath, scale, and center.
  3. For each persistent point, calculate sphere and wave-plane coordinates.
  4. Interpolate between them, project into screen pixels, and choose size/alpha.
  5. Sort by depth and stamp the cached glow sprite.

When something looks wrong

SymptomWhat to inspect
Blank canvasConfirm the canvas has a nonzero CSS height and the effect runs in the browser.
Blurry dotsMatch bitmap resolution to device pixel ratio and restore the context transform after resize.
No animationCheck reduced-motion settings, paused prop, tab visibility, and whether the canvas is onscreen.
A jump at two secondsReuse the same points and clamp/ease morph progress; do not swap renderers.
Clipped planeReduce world scale or the rightward center offset. Leave room for perspective and wave height.
High CPU usageReduce rows/columns first. The demo sorts 2,584 points per frame and allocates projected objects; reuse buffers or move to WebGL for much larger fields.
