LESSON 01

Understand what you are building

This is the bronze liquid effect from our React example: a nearly spherical silhouette, a dark warm body, a curved gold reflection, a bright glint, slow deformation, and fine grain. It is a 2D SVG illusion of a 3D surface. There is no fluid simulation, mesh, physical refraction, or ray tracing.

You already know React. The new skill is composing light and shape. We will use vanilla SVG and JavaScript for the live experiments, then put the same drawing into a complete React component. The tutorial itself works offline; its demos do not load React or any CDN.

LayerJob

Radial gradientSuggests a lit crown and shadowed lower surface.

Plan for 60–90 minutes. Read a step, change its live control, predict what happens, then inspect the code. Snippets are focused excerpts unless marked “complete”. The full component at the end contains everything.

LESSON 02

Give the drawing a coordinate system

Live SVG • stage 1

viewBox="0 0 800 760" defines an internal drawing space. Its first pair is the origin; its second pair is width and height. SVG scales those units to fit its CSS size. The origin is the upper left: x grows right and y grows downward.

Begin with a circle centered at (400, 375), radius 275. A circle gets us the rough composition, but a path will let us change individual parts of the outline.

React JSX — complete first component
export default function FirstDrop() {
 return (
  <svg viewBox="0 0 800 760" style={{ width: "100%", background: "#090704" }}>
   <circle cx="400" cy="375" r="275" fill="#87552f" />
  </svg>
 );
}
Try in your React app: change cx to 460. Only the position changes. Change r to 210. Only the size changes. Shrink the parent width: the internal coordinates still stay 800 × 760.

The stage above already uses our closed path, filled with one flat color. The next step explains how that outline is constructed.

LESSON 03

Draw curves with control points

A path’s d is a sequence of drawing instructions. M x y moves the pen. C x1 y1 x2 y2 x y draws a cubic Bézier curve from the current point, pulled toward two control points, ending at (x, y). Z closes the outline.

60

Drag the slider down toward 230. The endpoints stay fixed while the curve flattens. The curve is pulled toward the handles; it usually does not pass through them.

JavaScript — concept excerpt
// Vanilla JS: useful for understanding the geometry.
slider.addEventListener("input", () => {
 const y = Number(slider.value);
 curve.setAttribute("d", `M70 230 C180 ${y} 420 ${y} 530 230`);
});

Our drop joins six cubic segments. For smooth joins, the incoming and outgoing handles should roughly point along the same tangent. Wildly changing a handle can create a dent or sharp corner.

React JSX — focused excerpt
const SHAPE_A = "M400 100 C502 94 592 137 640 221 C690 306 692 413 640 506 C590 594 500 650 400 650 C296 654 199 604 151 514 C100 424 104 315 148 229 C195 140 294 103 400 100 Z";
Checkpoint: identify the endpoint of the first C command. It is (640, 221). The next C starts there automatically. The final segment returns to (400, 100), and Z closes the path.

LESSON 04

Turn a flat shape into a shaded volume

Live SVG • stage 2

A radial gradient blends outward from a center. The bright warm crown and nearly black lower area give a depth cue. The stops are artistic decisions, not a lighting calculation. Bronze appears convincing because the highlights are warm and the shadows remain very dark.

defs stores reusable resources. A definition does not draw itself. The path uses fill="url(#body)" to reference a gradient by its ID. Percentages below are relative to the shape’s bounding box.

React JSX — focused excerpt
<defs>
 <radialGradient id="body" cx="48%" cy="23%" r="78%">
  <stop offset="0" stopColor="#673519" />
  <stop offset=".32" stopColor="#3b1c0d" />
  <stop offset=".61" stopColor="#180c06" />
  <stop offset=".82" stopColor="#090704" />
  <stop offset="1" stopColor="#977140" />
 </radialGradient>
</defs>
<path d={SHAPE_A} fill="url(#body)" />

Moving the center changes the shading, even though the path is unchanged. This is the first part of the 3D illusion.

LESSON 05

Add reflections, then clip them

Live SVG • stage 3

A shiny object reflects large light sources as bands. Our gold strip is just a curved path with no fill and a wide stroke. A blurred amber ellipse suggests a soft lamp; a small white-to-transparent gradient makes the concentrated glint.

Drawing these shapes without restriction would let light spill outside the drop. A clipPath hides everything outside the silhouette. Reusing the same path through use keeps the body, clip, and rim synchronized when the silhouette changes.

React JSX — focused excerpt
<defs>
 <path id="shape" d={SHAPE_A} />
 <clipPath id="clip"><use href="#shape" /></clipPath>
 <filter id="soft" x="-30%" y="-50%" width="160%" height="200%">
  <feGaussianBlur stdDeviation="4" />
 </filter>
</defs>
<use href="#shape" fill="url(#body)" />
<g clipPath="url(#clip)">
 <path d="M83 346 C197 287 322 348 424 370 C535 394 617 437 665 497"
  fill="none" stroke="#c59355" strokeWidth="34" filter="url(#soft)" />
</g>

Uncheck to see the wide band extend beyond the surface. Re-enable to restore the material illusion.

Filter bounds are expanded so blur is not abruptly cut off by its own filter rectangle. The clip then intentionally trims the result to the liquid shape. SVG paints in DOM order, so the glint and rim come after the darker body.

LESSON 06

Morph compatible paths

Live SVG • stage 4

We define three related outlines A, B, and C. All use the same command sequence: M, six C commands, Z. The browser interpolates corresponding numbers. Keep the segment count, command types, and order identical; this approach does not automatically match arbitrary shapes.

For intuition, a coordinate halfway between 640 and 621 is 640 + (621 - 640) × 0.5 = 630.5. The same idea applies to every coordinate. Easing changes how quickly the interpolation fraction progresses.

React JSX — focused excerpt
<path id="shape" d={SHAPE_A}>
 <animate attributeName="d"
  values={[SHAPE_A, SHAPE_B, SHAPE_C, SHAPE_A].join(";")}
  dur="16s" repeatCount="indefinite"
  calcMode="spline" keyTimes="0;.333;.666;1"
  keySplines=".42 0 .58 1;.42 0 .58 1;.42 0 .58 1" />
</path>
PropertyMeaning
attributeName="d"Animate the path geometry.
valuesFour keyframes; the last repeats A for a seamless return.
dur="16s"Duration of the whole A → B → C → A cycle.
keyTimesNormalized timeline positions, from 0 to 1.
keySplinesThree easing curves, one per transition.
Scrub the timeline: 0s

Scrubbing pauses this demo. Use its Play button to continue from that time. Watch the edge; the motion is deliberately subtle.

This is SVG’s declarative animation system, commonly called SMIL. React does not need to update state every frame. The shape repeats after 16 seconds; “continuous” means smooth and ongoing, not mathematically non-repeating.

LESSON 07

Separate floating from surface motion

Live SVG • final composition

Wrap the drop in a group and translate that group up and down. Inside it, the silhouette morphs over 16 seconds, while the reflection sweeps over 13 seconds. Different durations make the combined motion less obviously synchronized.

React JSX — focused excerpt
<g>
 <animateTransform attributeName="transform" type="translate"
  values="0 6;0 -8;0 6" dur="8s" repeatCount="indefinite"
  calcMode="spline" keyTimes="0;.5;1"
  keySplines=".42 0 .58 1;.42 0 .58 1" />
 {/* body, clipped highlights, and rim go here */}
</g>

Keep transformation ownership separate. If you later add pointer rotation, put it on an outer group instead of overwriting this group’s animated transform. A displacement filter could add ripples, but it is unnecessary for this smooth, restrained look.

Finish with a small amount of grain

Static fractal noise adds surface texture to the composition. It is an aesthetic overlay, not a simulation of the metal. Lower opacity is usually better.

React JSX — focused excerpt
<filter id="grain">
 <feTurbulence type="fractalNoise" baseFrequency=".85"
  numOctaves="3" stitchTiles="stitch" />
 <feColorMatrix type="saturate" values="0" />
</filter>
<rect width="800" height="760" filter="url(#grain)"
 opacity=".045" pointerEvents="none" />

LESSON 08

Bring it into React correctly

SVG belongs directly inside JSX. Convert hyphenated attributes such as stroke-width to strokeWidth and clip-path to clipPath. Keep aria-label hyphenated. CSS style strings become objects.

Use a ref to access the SVG timeline. React state represents the desired paused state. An effect applies that state to the SVG. Avoid changing button text manually in React: derive it from state.

React JSX — focused excerpt
const svgRef = useRef(null);
const [paused, setPaused] = useState(false);
useEffect(() => {
 const svg = svgRef.current;
 if (!svg) return;
 if (paused) svg.pauseAnimations();
 else svg.unpauseAnimations();
}, [paused]);
// In the JSX:
<svg ref={svgRef}>...</svg>
<button onClick={() => setPaused(p => !p)}>
 {paused ? "Play animation" : "Pause animation"}
</button>

Make each instance independent

If two drops share IDs like “body” or “clip”, fragment references can point to the wrong resource. Generate a unique prefix once per component with useId, then use it for every definition and reference. Do not generate random IDs during render.

React JSX — focused excerpt
const id = useId();
<radialGradient id={`${id}-body`}>...</radialGradient>
<path fill={`url(#${id}-body)`} d={SHAPE_A} />

Respect motion preferences

CSS reduced-motion rules alone do not stop SVG SMIL. Read the media query and pause the SVG timeline. The complete component subscribes to preference changes and removes its listener on unmount. Its Play button lets someone explicitly resume the animation.

For a purely decorative background, use aria-hidden="true" on the SVG and keep meaningful text outside it. In this standalone study we provide an accessible image label.

LESSON 09

Use the complete component

This is the full JavaScript/JSX implementation. Copy it to BronzeLiquid.jsx in an existing React project. It includes the SVG, all three paths, per-instance IDs, controls, and reduced-motion handling. It has no animation dependencies.

In Next.js App Router, keep the "use client" directive because the component uses hooks and browser methods. In a standard React client app it is harmless. If converting to TypeScript, type the ref as useRef<SVGSVGElement | null>(null).

BronzeLiquid.jsx — COMPLETE component
"use client";
import { useEffect, useId, useRef, useState } from "react";

// Self-contained: no animation packages or external styles.
export default function BronzeLiquid() {
 const id = useId(); // Unique gradient, filter and clip IDs for every instance.
 const svgRef = useRef(null);
 const [paused, setPaused] = useState(false);
 useEffect(() => {
   const media = window.matchMedia("(prefers-reduced-motion: reduce)");
   const sync = () => setPaused(media.matches);
   sync();
   media.addEventListener("change", sync);
   return () => media.removeEventListener("change", sync);
 }, []);
 useEffect(() => {
   const svg = svgRef.current;
   if (!svg) return;
   if (paused) svg.pauseAnimations();
   else svg.unpauseAnimations();
 }, [paused]);

  <section style={{ position: "relative", background: "#090704", color: "#e7e3d7", maxWidth: 900, margin: "auto" }}>
   <div style={{ aspectRatio: "800 / 760" }}>

 <radialGradient id={`${id}-body`} cx="48%" cy="23%" r="78%">
  <stop stopColor="#673519"/><stop offset=".32" stopColor="#3b1c0d"/>

LESSON 10

Debug, experiment, and finish

SymptomCheck
Shape jumps instead of morphingSame path commands and number of coordinates in every keyframe?
Drop is flatEnough contrast? Dark body plus a narrow bright reflection?
Harsh rectangular blur edgeExpand filter x/y/width/height bounds.
Second component looks wrongUnique IDs for every gradient, filter, path and clip?
Pause does not workCall pauseAnimations on the outer SVG, not a path or group.
Animation starts pausedCheck the operating system’s reduced-motion setting.
Phone rendering is expensiveRemove grain first, reduce filter area, and avoid many large blurred copies. Profile before adding complexity.

Three practice tasks

  1. Make a silver version: replace warm stops with neutral grays, keep near-white highlights and dark shadows.
  2. Make a slower version: double all three durations. Predict the new complete shape cycle before running it.
  3. Render two drops side by side, pause only one, and verify their gradients and clips stay independent.
Why not simply use border-radius animation?

It can make a quick blob, but gives less direct control over local curvature. SVG lets us shape individual curves and reuse the exact outline for clipping reflections.

When would Three.js become useful?

When you need a real camera, surface normals, scene lighting, environment reflections, or geometry that responds naturally to rotation. This SVG technique is best for an art-directed hero illustration with a fixed viewpoint.
